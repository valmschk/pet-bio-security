# BioVault

**Микросервис аутентификации и авторизации** для защиты медицинских и персональных данных (биометрия, история болезней).

> **Смысл:** мед данные требуют защиты. Никто не должен иметь доступ к биометрии другого пользователя. Сервис выдаёт JWT-токен, и другие микросервисы понимают, кто делает запрос и какие у него права.

## Возможности

- **Stateless-авторизация (JWT)** — сервер не хранит сессии, упрощает масштабирование.
- **Разграничение ролей** — `ROLE_USER` и `ROLE_ADMIN`.
- **Blacklist токенов через Redis** — при логауте токен отзывается, и повторно его использовать нельзя.
- **Production-Ready probes** — чтобы K8s сам перезапускал зависший сервис.
- **CI/CD через GitHub Actions** — автоматическая сборка, тесты и пуш Docker-образа при каждом `git push`.

## Технологии

Java, Spring Boot, Spring Security, PostgreSQL, Redis, Docker, Kubernetes, GitHub Actions
